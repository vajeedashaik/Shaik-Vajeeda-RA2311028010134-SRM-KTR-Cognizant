Reference copy from the live project at Solutions/6. Spring Data JPA + Hibernate/orm-learn/ — see 07-Spring-Data-JPA-Hibernate.md in the guide/ folder for how to actually run it (needs MySQL via Docker).

Schema note: the exercise's schema (quiz.mwb) is generated via MySQL Workbench, which isn't available in this environment, so the quiz tables (quiz_user, question, options, attempt, attempt_question, attempt_option) were hand-authored directly in schema.sql/data.sql instead, following the table/column layout described in Question.md. The "user" table is named quiz_user here because USER is a reserved word in MySQL. Sample data reproduces the exact 4-question HTML quiz and answers shown in Question.md so testGetAttemptDetail() in OrmLearnApplication prints matching output.
