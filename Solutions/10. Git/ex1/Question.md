Objectives
Explain the need and benefit of Git as a distributed version control system
Explain how to install and configure Git
Explain how to integrate a text editor with Git
Explain how to create a local Git repository and make the first commit
Explain how to connect a local repository to a remote Git repository and push changes
In this hands-on lab, you will learn how to:
Verify the Git installation and configure your user identity
Integrate Notepad++ as the default Git editor
Create a local repository and initialize it with Git
Create, stage and commit a file
Connect the local repository to a remote repository on GitLab and push the first commit
Prerequisites
The following are the pre-requisites to complete this hands-on lab:
Git Bash installed
Notepad++ installed
A free account on GitLab
Hands-on ID: "Git-T01-HOL_001"
Notes*:
Please follow the below steps for creating a free account on GitLab.
Do not use Cognizant credentials to login to GitLab.
Estimated time to complete this lab: 30 minutes.
Please follow the instructions to complete the hands-on. Each instruction expects a command for the Git Bash.
Verify that Git is installed and check its version.
Configure your Git user name and email at the global level and verify the configuration.
Configure Notepad++ as the default editor used by Git for commit messages.
Create a local folder named "GitDemo" and initialize it as a Git repository.
Create a file named "welcome.txt" with some sample content.
Check the status of the repository, stage the file, and commit it with a meaningful commit message.
Create a new project named "GitDemo" on GitLab.
Add the GitLab project as a remote named "origin" and push the first commit to the "master" branch.
Verify that "welcome.txt" appears in the remote repository on GitLab.
